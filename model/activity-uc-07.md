# Activity Diagram UC-07 «Згенерувати список покупок»

Діаграма показує послідовність дій під час генерації списку покупок на основі тижневого розкладу та перевірку наявності запланованих страв. Залежно від результату перевірки сценарій завершується або відхиленням з виведенням повідомлення (FR-12), або успішною генерацією зведеного списку (FR-11, NFR-02).

```mermaid
flowchart TD
    A((Початок)) --> B[Користувач ініціює генерацію списку покупок]
    B --> C[Система перевіряє тижневий розклад]
    C --> D{Є заплановані страви?}

    D -- Ні --> E[Повідомити про необхідність додати страви]
    E --> F((Кінець))

    D -- Так --> G[Зібрати інгредієнти з усіх рецептів]
    G --> H[Згрупувати однакові інгредієнти]
    H --> I[Підсумувати кількість до 3 знаків після коми]
    I --> J[Сформувати та відобразити список покупок]
    J --> K[Повідомити про успішну генерацію]
    K --> L((Кінець))
```
