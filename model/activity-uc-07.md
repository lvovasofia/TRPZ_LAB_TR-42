# Activity Diagram UC-07 «Згенерувати список покупок»

Діаграма показує послідовність дій під час генерації списку покупок на основі тижневого розкладу та перевірку наявності запланованих страв. Залежно від результату перевірки сценарій завершується або відхиленням з виведенням повідомлення (FR-12), або успішною генерацією зведеного списку (FR-11, NFR-02).

```mermaid
flowchart TD
    A((Початок)) --> B[Користувач ініціює<br/>генерацію списку покупок]
    B --> C[Система перевіряє <br/> тижневий розклад]
    C --> D{Є заплановані <br/> страви?}

    D -- Ні --> E[Повідомити <br/> про необхідність <br/> додати страви]
    E --> F((Кінець))

    D -- Так --> G[Зібрати інгредієнти <br/> з усіх рецептів]
    G --> H[Згрупувати однакові інгредієнти]
    H --> I[Підсумувати кількість <br/> до 3 знаків <br/> після коми]
    I --> J[Сформувати та <br/> відобразити список покупок]
    J --> K[Повідомити про <br/> успішну генерацію]
    K --> L((Кінець))
```
